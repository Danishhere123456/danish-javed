# Danish Javed — Health & Research

A lightweight, no-build personal profile site for GitHub Pages.

## Editing

- Update the public wording in `index.html`.
- Adjust the visual system in `styles.css`.
- `script.js` only updates the footer year automatically.

The site is intentionally static, so it remains readable and search-friendly without JavaScript.

## Publishing

GitHub Pages serves this repository directly from the `main` branch and its root folder. There is no build step.
