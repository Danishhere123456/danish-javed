# Personal profile site

A fast, no-build personal website designed for GitHub Pages. It is intentionally content-first: the design is complete, while the personal details live in one small file.

## Personalize it

Open `profile.js` and replace the sample values with your real name, headline, biography, interests, links, and contact details. Any link left blank is automatically hidden.

## Publish with GitHub Pages

1. Create an empty GitHub repository.
2. Upload every file in this folder to the repository's top level.
3. In the repository settings, enable GitHub Pages using the default branch and its root folder.
4. GitHub will provide the public address once publishing finishes.

There is no installation or build step: GitHub Pages can serve these files directly.
